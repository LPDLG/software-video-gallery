# 软件介绍视频库

一个基于 GitHub Pages 的软件介绍视频播放站点。每个视频均拥有独立播放页面和二维码。

## 在线访问

<https://lpdlg.github.io/software-video-gallery/>

## 视频来源

视频文件来自用户提供目录：

`F:\DSH\video-denoise\watermark_task\out`

网站共收录 12 个 MP4 视频，其中 Unity 视频由用户随后补充。

## 说明

- 播放网页：`watch.html?v=视频序号`
- 二维码：`qr/`
- 视频文件：`videos/`
- 本仓库公开发布，二维码无需登录即可访问。

# 人工智能艺术教学视频库

一个基于 GitHub Pages 的人工智能艺术教学视频站点。每个视频均拥有独立播放页面和二维码。

## 在线访问

<https://lpdlg.github.io/software-video-gallery/>

## 视频内容

- 12 个软件介绍视频
- 10 个前9章课程视频，其中第5章包含整章版与实操节选
- 14 个第19章实验教学视频

新增课程视频来自用户提供目录：

`F:\Lab_8118\软件介绍视频\教学视频最终版汇总_前9章与第19章`

网站共收录 36 个 MP4 视频。

## 说明

- 播放网页：`watch.html?v=视频序号`
- 二维码：`qr/`
- 视频文件：`videos/`
- 本仓库公开发布，二维码无需登录即可访问。
